# UI-Drawings
Below are three wireframe / UI drawings for my web application, *Think or Sink*.<br>
This is a time-based trivia game, and the drawings included are the home page, the game page, and the results page.<br>
**The black boxes and their text labels are strictly for wireframe/design purposes and will not be included in the final product.**

__________________________________________________________________________________________________________________

<h2>Home Page</h2>
Here, the user has a chance to pick their desired trivia topic, around which all of the questions and answers will be centered.
After clicking the start button, the water will drain from the background, and the game will begin.

__________________________________________________________________________________________________________________

<h2>Game Page</h2>
Here is where the actual game is played. The user has a designated time limit, and the water rises relative to the amount of time left.
As the amount of time left decreases, the water level increases. Any correct answer will slightly increase the time, lowering the water level.
The user is instantly notified if their answer is correct or incorrect. The game ends once the timer runs out / water fills the background.

__________________________________________________________________________________________________________________

<h2>Results Page</h2>
Here is where the user is taken after the game has ended. Their score and number of questions answered correctly will be displayed.
The user will have the option to play the same topic again, or return to the main menu to pick another topic.
